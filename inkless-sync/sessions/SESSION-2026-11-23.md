## Learnings
- Check the tiered-storage plugin against the new Kafka version before the sync. A plugin release built against the old Kafka fails at broker startup, not at compile time.
- Git's rename detection moved the inkless edits of a deleted Scala file into its new Java replacement (`QuotaFactory`). Read the new file, not only the conflict list.
- The script's auto-resolvable list doesn't resolve anything. Every file in it stayed unmerged.
- Merging the sync PR needs a repository administrator to lift the signed-commit and linear-history rules.
