# Agent rules for proposals

This folder holds stable versions of design proposals. [VERSIONS.md](VERSIONS.md)
describes each version.

Agents MUST NOT create, edit, move, rename, or delete any file in this folder or
its subfolders unless the user explicitly consents to that specific change. This
rule covers `VERSIONS.md`, this `AGENTS.md` file, and every version folder.

- A request to work on a design isn't consent to change a stored version. If a
  task seems to need a change here, ask the user first and wait for their answer.
- If the user wants to iterate on a design, ask whether to create a new version
  folder. Don't edit an existing version in place.
- Reading these files is always allowed.
